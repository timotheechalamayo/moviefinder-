# Tim & Paulis Filmfinder

Tinder-artiger Filmfinder im Browser. Jede Person swipt auf dem eigenen Handy, per Link tauscht ihr eure Likes aus und seht eure gemeinsamen Filme (Matches). Filterbar nach IMDb-Mindestbewertung und Genre.

- Alles steckt in `index.html` (4.083 Filme mit IMDb-Bewertung, Stand der Daten: bis 2016).
- Gespeichert wird nur im eigenen Browser, kein Server und kein Konto nötig.
